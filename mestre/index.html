O que foi melhorado

Semântica

Uso de elementos corretos (`header`, `main`, `section`, `article`) para acessibilidade e manutenção.

Responsividade

Layout fluido com grid/flex e breakpoints simples para funcionar bem em mobile e desktop.

Escalabilidade

Tokens CSS para cores, espaçamentos e sombras facilitam alterações sem retrabalho.

Padrão visual consistente

A folha de estilo foi organizada por blocos: reset leve, tokens, layout e componentes. Isso reduz duplicidade e deixa o CSS mais previsível.

Resumo técnico

  • Tipografia com `clamp`.
  • Container central reutilizável.
  • Botões e cards padronizados.
  • Foco visível para teclado.

Feito para ser uma base sólida de front-end.
